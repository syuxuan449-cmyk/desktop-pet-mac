桌面小伙伴 v4 · Mac 版 使用说明

适用：macOS 10.13 及以上（已按 macOS Sequoia 15.5、Intel 芯片适配）。无需安装 Xcode 或任何软件。

一、解压
双击「桌面小伙伴-Mac.zip」，得到「桌面小伙伴.app」。建议把它拖进「应用程序」文件夹（放桌面也可以）。

二、第一次打开（系统会拦截，因为这个 App 没有苹果开发者签名）
方法 A（推荐）：
  1. 双击「桌面小伙伴.app」，出现“无法打开 / 无法验证开发者”的提示时点「完成」或「好」。
  2. 打开「系统设置」→「隐私与安全性」，向下滚动到“安全性”，
     看到“已阻止使用「桌面小伙伴」”，点「仍要打开」，输入开机密码确认。
  3. 再双击一次 App，在弹窗里点「打开」。
  （旧版 macOS 也可以右键 App →「打开」→「打开」。macOS 15 Sequoia 起右键打开不再能跳过拦截，请用上面的方法。）
方法 B（终端一行命令）：
  打开「终端」，输入下面这行（路径按你实际放的位置改），回车：
  xattr -dr com.apple.quarantine /Applications/桌面小伙伴.app
  之后就能直接双击打开。
以后再打开就不会被拦截了。

三、互动
· 单击头部/身体：摸摸，开心表情 + 爱心 + 对话，好感度 +1。
· 拖动人物：移到屏幕任意位置。
· 双击人物：跳舞/弹跳。
· 底部「喂食」：吃东西，好感度 +2，结束后自动回到待机。
· 底部「睡觉」：休息；再点一次（按钮变成「醒来」）即醒来。
· 底部「打屁屁」，或单击人物最下方约 28% 的区域：生气 + 红色怒气符号 + 摇晃，好感度 -2（最低 0），约 2.3 秒后恢复待机，期间不能连续触发。
· 右键人物，或点击「⋯」：打开完整菜单（喂食 / 睡觉 / 打屁屁 / 跳个舞 / 回到屏幕右下角 / 退出桌宠）。
· Esc：只隐藏工具栏，不会退出。右键人物即可再次显示。
· 桌宠不会出现在程序坞里，会一直浮在其他窗口上方，切换桌面也会跟着你。
· 好感度和 Windows 原版一样只在本次运行中有效，退出后从 0 开始。

四、退出
右键人物 →「退出桌宠」；或者先点一下桌宠，再按 ⌘Q。

五、遇到问题
· 双击 App 没反应：双击同一文件夹里的「启动桌宠（备用）.command」，终端里会显示具体错误；
  也可以查看日志：~/资源库/Logs/桌面小伙伴.log（访达 → 前往 → 前往文件夹 → 输入 ~/Library/Logs）。
· .command 也被拦截：同样到「系统设置 → 隐私与安全性」点「仍要打开」，或运行
  xattr -dr com.apple.quarantine 后面接这个文件夹的路径。
· 本 App 不需要辅助功能、屏幕录制等任何权限；如果系统弹窗询问，可以直接拒绝。
